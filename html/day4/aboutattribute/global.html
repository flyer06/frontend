Global Attribute in HTML A global attribute is an HTML attribute that can be used with almost any HTML element. Examples: id – gives a unique name to an element. class – assigns one or more classes. style – adds CSS styles. title – displays extra information when the mouse hovers over an element. hidden – hides an element.
