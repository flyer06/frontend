1. What is HTML?

HTML stands for HyperText Markup Language.

HTML is a markup language used to create and structure content on webpages.

Is HTML a Programming Language?

No. HTML is not a programming language. It is a markup language because it uses tags to describe the structure of content.

3. HTML Tags and Elements

HTML Tag

A tag is written inside angle brackets.

Example: <p>

HTML Element

An element generally contains an opening tag, content and a closing tag.

Example: <p>Hello World</p>

4. DOCTYPE Declaration

The <!DOCTYPE html> declaration tells the browser that the document uses HTML5.

DOCTYPE is a declaration, not an HTML tag.

5. Basic HTML Structure

An HTML document contains three important structural parts:

  • <html> - Root element
  • <head> - Contains metadata
  • <body> - Contains visible content

15. Open Graph (OG)

Open Graph metadata controls how a webpage can be represented when it is shared on platforms that support Open Graph.

  • og:title - Title of the shared page
  • og:type - Type of content
  • og:image - Preview image
  • og:url - Page URL
  • og:description - Short description
