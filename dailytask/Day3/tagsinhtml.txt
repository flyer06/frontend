If you mean all HTML tags/elements available in modern HTML, here is a more complete list, grouped by purpose.

Document structure
<html> — root element
<head> — document metadata
<body> — visible page content
<title> — page title
<base> — base URL for relative URLs
Metadata
<meta> — metadata
<link> — external resources, such as CSS
<style> — internal CSS
Sectioning / semantic elements
<header> — introductory/header content
<footer> — footer content
<main> — main content
<nav> — navigation links
<section> — thematic section
<article> — independent content
<aside> — related/sidebar content
<address> — contact information
<h1> — <h6> — headings
<hgroup> — heading group
Text/content
<p> — paragraph
<div> — generic block container
<span> — generic inline container
<br> — line break
<hr> — thematic break
<pre> — preformatted text
<blockquote> — block quotation
<q> — inline quotation
<figure> — self-contained content
<figcaption> — figure caption
Text formatting / semantics
<strong> — strong importance
<b> — stylistically bold text
<em> — emphasis
<i> — alternate voice/mood
<u> — annotation/underline
<s> — no-longer-accurate text
<small> — small print
<mark> — highlighted text
<del> — deleted text
<ins> — inserted text
<sub> — subscript
<sup> — superscript
<abbr> — abbreviation
<cite> — title of a work
<dfn> — defining instance of a term
<code> — code
<kbd> — keyboard input
<samp> — sample output
<var> — variable
<data> — machine-readable value
<time> — date/time
<bdi> — bidirectional isolation
<bdo> — bidirectional text override
<ruby> — ruby annotation
<rt> — ruby text
<rp> — ruby fallback parentheses
<wbr> — possible word-break location
Links
<a> — hyperlink
<area> — clickable area in an image map
<map> — image map
Images
<img> — image
<picture> — responsive images
<source> — media/image source
Audio and video
<audio> — audio
<video> — video
<track> — subtitles/captions
Lists
<ul> — unordered list
<ol> — ordered list
<li> — list item
<dl> — description list
<dt> — description term
<dd> — description/details
Tables
<table> — table
<caption> — table caption
<thead> — table header section
<tbody> — table body
<tfoot> — table footer
<tr> — table row
<th> — header cell
<td> — data cell
<colgroup> — group of columns
<col> — column definition
Forms
<form> — form
<label> — label for a form control
<input> — input control
<button> — button
<textarea> — multiline text input
<select> — dropdown/list
<option> — option
<optgroup> — group of options
<datalist> — predefined input options
<fieldset> — group of form controls
<legend> — fieldset caption
<output> — calculation/result
<progress> — progress indicator
<meter> — scalar measurement
Interactive elements
<details> — expandable content
<summary> — heading for <details>
<dialog> — dialog/modal
Embedded content
<iframe> — embedded webpage
<embed> — embedded external content
<object> — external resource
<canvas> — programmable graphics
<svg> — vector graphics
<math> — MathML content
Scripting / Web Components
<script> — JavaScript or other scripts
<noscript> — content shown when scripting isn't available
<template> — inert HTML template
<slot> — Web Component slot
Special HTML elements
<search> — search/control area
<selectedcontent> — selected option's rendered content
<geolocation> — experimental/limited-support element in some implementations
Important: <!DOCTYPE html>

<!DOCTYPE html> is not an HTML tag. It is a document-type declaration that tells the browser to use standards mode.

Deprecated/obsolete tags

You may encounter these in old websites, but don't use them for new development:

<font>
<center>
<big>
<strike>
<tt>
<acronym>
<frameset>
<frame>
<noframes>
<dir>
<applet>
<basefont>
<bgsound>
<blink>
<marquee>
<spacer>

Also remember that HTML attributes are different from tags. For example:

<a href="https://example.com" target="_blank" class="link">
    Example
</a>


Here, <a> is the tag, while href, target, and class are attributes.
